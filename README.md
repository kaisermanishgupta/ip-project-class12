# PesaCharge - Mobile & DTH Recharge System

A Java-based Windows desktop application developed as a **Class 12th Information Practices (IP) project**.

The project is a simplified clone of a mobile and DTH recharge platform, allowing users to perform recharge operations through a graphical desktop interface.

## 📌 Project Overview

The application provides a basic recharge management system for:

- 📱 Mobile Recharge
- 📺 DTH Recharge
- 👤 User details
- 💳 Recharge transactions
- 🗄️ Database-backed records

The project was developed to demonstrate the practical use of **Java GUI programming, SQL databases, and database connectivity**.

## 🛠️ Technologies Used

- **Java**
- **NetBeans IDE**
- **SQL**
- **JDBC**
- Java Swing / GUI
- Relational Database

## ✨ Features

- User-friendly desktop GUI
- Mobile recharge functionality
- DTH recharge functionality
- Recharge plan/details management
- Transaction storage using SQL
- Database connectivity through JDBC
